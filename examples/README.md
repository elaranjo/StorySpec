# Complete StorySpec examples

These four local projects each contain an accepted manuscript, linked narrative coverage, recorded human reviews, an applied spec, and an archived change. Open one folder and run `storyspec status opening --json` or `storyspec history opening`.

| Profile | English | Português |
| --- | --- | --- |
| Novel | [novel-en](novel-en/) | [novel-pt](novel-pt/) |
| Light Novel | [light-novel-en](light-novel-en/) | [light-novel-pt](light-novel-pt/) |

The stories are small teaching examples. Their facts are not part of a user's project canon.
