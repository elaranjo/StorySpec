# Contributing to StorySpec

StorySpec is a local, provider-independent framework for writers of novels and light novels. Please open an issue before changing a public file format or approval rule; existing projects must remain readable.

Run `npm test` before proposing a change. Add an EN/PT case for new user-facing messages and a clean-project case for new workflow steps. Tests must distinguish structural checks from literary judgment; a person's recorded assessment remains required for realized narrative requirements.

Do not include private manuscripts, unpublished story material, API keys, or personal data in issues, tests, or pull requests. Use a short fictional example when reporting a defect. Public feedback can use the [author feedback guide](docs/author-feedback.md).
