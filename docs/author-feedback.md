# Author feedback after the public release

Writers can report whether they completed a change using only the README, tutorial, CLI, and local files. Please do not upload a real unpublished manuscript. A short fictional example is enough.

Useful details:

1. Language and profile: EN/PT, Novel/Light Novel.
2. Installation method and Node.js version.
3. Last completed command and the first step that was unclear.
4. The exact CLI error or JSON issue ID, with private paths and prose removed.
5. Whether the writer understood why a human assessment, waiver, or reapproval was required.
6. Whether the change reached `ARCHIVED` and `storyspec history` reported `verified: true`.

The initial post-release target is three independent writers, including use in both languages. Record issues and fixes publicly only with the writer's consent; aggregate results can be reported without names or story content.
